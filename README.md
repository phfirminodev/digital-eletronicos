# DIGITAL Eletrônicos — Website Oficial (Nicho Tech)

Plataforma web de alta performance desenvolvida para a **DIGITAL Eletrônicos** (Itapoã - DF). O projeto une assistência técnica especializada em celulares, eletromobilidade (motos e patinetes elétricos) e vitrine de acessórios, estruturado em um design minimalista e editorial baseado no padrão da [OpenMac](https://www.openmac.com.br/).

---

## 🚀 Tecnologias Utilizadas

- **React 19** — Interface declarativa, modular e reativa
- **Vite 8** — Build ultrarrápido com hot module replacement (HMR)
- **Tailwind CSS v4** — Estilização moderna e responsiva
- **Lucide Icons** — Conjunto de ícones minimalistas de alta precisão
- **Google Fonts** — Tipografia editorial (*Sora* e *Inter/Manrope*)

---

## ✨ Principais Recursos

1. **Design Minimalista Editorial**: Paleta *warm paper* (`#f5f3ee`), tipografia elegante de alto contraste e realces em cobre/bronze metálico da marca.
2. **Rastreamento de Ordem de Serviço (OS)**: Consulta de status de reparo em tempo real com linha do tempo de 4 etapas (*Entrada, Diagnóstico, Bancada e Retirada*).
3. **Showroom de Eletromobilidade**: Destaque para venda e oficina de scooters e patinetes elétricos, bateria de lítio e economia urbana.
4. **Vitrine & Acessórios**: Destaques de produtos, caixas de som FAM, carregadores turbo GaN 65W e películas.
5. **Integração Comercial**: Links rápidos para WhatsApp com mensagens pré-formatadas para orçamentos, Instagram oficial ([@digital.eletronicos.itp](https://www.instagram.com/digital.eletronicos.itp)) e rota no Google Maps.

---

## 🛠️ Como Executar o Projeto

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento local
npm run dev

# 3. Compilar versão final de produção
npm run build

# 4. Pré-visualizar a versão compilada
npm run preview
```
